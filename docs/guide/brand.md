# Brand and motion

Xenon's mark is one continuous rounded X, with an open center and no crossing
bars. The three-layer loading animation uses the same cross section.

[Open the logo editor](/brand/editor/index.html) ·
[Compare loading spinners](/brand/spinners/index.html)

## Loading spinners

| Staggered | Counter-rotation | Continuous |
| --- | --- | --- |
| ![Staggered loading animation](/brand/spinners/stagger.svg) | ![Counter-rotating loading animation](/brand/spinners/counter.svg) | ![Continuous loading animation](/brand/spinners/orbit.svg) |

These standalone SVG animations respect reduced-motion preferences. White-on-black
variants are included. The 3D editor provides geometry controls, camera views,
per-disc easing curves, and static GLB export.

The editor needs network access for its pinned Three.js imports. The static logo
and SVG spinners have no runtime dependencies.
